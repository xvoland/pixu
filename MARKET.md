## 2. Short Description (one sentence)

**pixu** is a fast, terminal-based image viewer written in Go that renders pictures
directly in your command line using every protocol available: RGB, grayscale,
256-color, ASCII art, plus Kitty/iTerm2 (TGP) and Sixel.

---

## 3. Medium Description (a few sentences)

**pixu** turns an ordinary terminal into a full-featured image viewer. It supports
RGB, grayscale, 256-color and ASCII-art modes, as well as modern graphics protocols
Kitty and iTerm2 (TGP) and Sixel for xterm/mlterm — you can pick a mode manually or
let it auto-detect the best one for your terminal. The tool is cross-platform
(Linux, macOS, Windows), written in Go with no runtime dependencies, and can paste
images from the clipboard, scale them, and fit them to the window size. pixu is free
and open source, and the author accepts support through a QR code shown right in the
terminal with the `pixu --qr` command. If the tool was useful, please back the
project with a donation — it helps drive new features forward.
